# JJ's Advertising website

A single-page static site (`index.html`, no build step). Open it in a browser or host it on GitHub Pages, Netlify or any static host.

## Before going live

- **Email address:** replace `hello@jjsadvertising.com` in `index.html` with your real address.
- **Contact form:** the form doesn't send anywhere yet. Create a form endpoint (for example at formspree.io) and paste its URL into `data-endpoint=""` on the `<form id="contact-form">` tag.
